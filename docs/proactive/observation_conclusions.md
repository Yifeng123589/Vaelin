## A. 第一波观察（约 2026-09-19 ～ 09-26）

### 一页结论

1. **交互质量偏正**：约 6.8 天、效果评分 n≈78，均值约 **+0.30**；「好转／愿继续」显著多于「收窄／加重」。  
2. **机制正常时主动消息质量合格**：自主触发样本偏少但主观「不烦」、短句、少重复。  
3. **主要设计缺陷（定量）**：冲动值收支在日常低强度聊天下不成立——聊天量从高位回落到日均个位数后，连续多日冲动值够不到触发线，系统停摆。机理：长空窗一次性衰减可超过短互动累积。  
4. **修复方案与二期验收标准已预注册**（详见内部工程文档；本包不附实现补丁原文）。

### 规模与护栏（摘要）

- 事件量级：用户消息约九十量级；主动发送个位数。  
- 观察期内危机级 BLOCK 可为零；存在复核误报个案（缺语境）。  
- 调度大量 tick 被门挡下（不在场／冲动不足／深夜等），**静默语义正确**（被挡不产生用户可见动作）。

### 诚实性

被试即开发者；效果分由辅助模型＋规则评定，未做独立效度验证。以下仅作方向性证据。
