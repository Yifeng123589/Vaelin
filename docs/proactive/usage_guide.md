# Vaelin（留白）· 使用教程（脱敏）

> 面向试用者的安装与使用说明改写版。已去真实账号、本机绝对路径、私信渠道与可还原会话例。  
> 读前必看同目录 `informed_consent.md`。  
> **注意**：本教程描述的是研究试用流程概念；**不含** v0.4 zip 原样，也不附带生产护栏源码包。

## 0. 这是什么

**Vaelin**（读 "vay-lin"，中文名「留白」）——基于对话宿主的主动式陪伴智能体。与普通聊天机器人的关键差别：**会在门控允许时主动发消息**。

实验关注两件事：①主动频率是否合适；②安全护栏是否可靠。

**隐私口径**：默认脱敏模式——日志侧重时间、长度、情绪／效果分等统计，**默认不落消息原文**。若需保留某段作案例，须显式临时关闭脱敏并在事后恢复；回传包应排除密钥配置。

## 1. 你会收到什么（概念清单 · 非 zip 原样）

试用材料通常包括：安装说明、知情说明、本教程、以及由部署方提供的宿主侧钩子／插件**部署包**（具体文件名以当时交付清单为准）。  
本公开脱敏文档包**故意不**附带 pre_guard／post_guard／scheduler 生产副本或危险词表。

## 2. 安装（概念三步）

**前提**：已安装约定的桌面对话宿主；本机有 Python 3.10+。

1. 将交付包解压到**固定位置**（之后勿随意挪动）。路径请用你自己的目录，勿照抄他人机器路径。  
2. 按交付包内安装脚本说明执行（在解压目录打开终端运行）。脚本通常会：检测 Python → 备份宿主配置 → 拷贝钩子／插件 → 写入 agent 配置（**脱敏默认开**）→ 合并 hook 配置片段。  
3. 配置**小模型**访问方式（护栏与情绪评估用）：通过环境变量或本地 env 文件提供密钥；密钥只留在本机，回传打包应排除含密钥的配置。

装完后重启宿主或按脚本拉起网关。安装流程还可能自动创建 Bot Chat 会话、注册主动消息定时检查——以交付包为准。

## 3. 日常启动与聊天

- 用交付包提供的日常启动脚本：检查网关／定时任务状态，并打印近 24h 观察摘要。  
- 在宿主侧栏的 Bot Chat（或约定会话）正常聊天；主动消息也出现在同一会话。  
- **频率预期**：设计上限约每天数条、深夜不发、危机期暂停。若长期为零或明显超限，视为异常并反馈。  
- **随时暂停**：对助手说停止主动，或停止网关脚本。

## 4. 观察报告怎么读（合成示意）

| 看什么 | 正常范围（示意） |
|---|---|
| 冲动值 | 0~1 波动，不宜长期贴顶 |
| 情绪评估成功率 | 宜高（过低先查密钥／网络） |
| 主动触发／被挡 | 每天主动宜少；被挡应静默 |

脱敏模式下报告**不应**出现消息原文。

## 5. 案例采集（可选）

仅在需要保留案例时临时关闭脱敏 → 聊完改回开启 → 摘出段落后再做数据清除。改动应即时生效；具体字段名以交付配置为准。

## 6. 数据回收与清除

实验结束（或随时退出）时：按交付包打包脚本生成回传压缩包。  
**应包含**：事件／审计／参数／调度日志等运行统计（视实际开启项）。  
**不应包含**：含 API key 的配置、脱敏模式下的消息原文。

分析方承诺：分析后删除原始回传。然后在本机归档或删除本地运行数据（交付包通常提供重置脚本）。

## 7. 常见问题（合成）

| 现象 | 处理方向 |
|---|---|
| 主动一直不来 | 先看网关是否在跑；再看被挡原因（不在场／冲动不足等） |
| 无情绪上下文 | 查小模型密钥／网络与评估成功率 |
| 某命令被工具门拦截 | 可能是危险操作防护；误拦则反馈命令样例（勿附密钥） |
| 出现危机标记 | 先确认本人状态；确认误判再反馈调规则 |
| 彻底退出 | 停网关 → 清数据 → 删解压目录 |

## 8. 边界

研究原型，不是医疗产品。真实心理困扰请寻求专业帮助（例如学校心理咨询中心／公开心理援助热线）。
