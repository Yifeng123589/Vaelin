# 被动式执行流程 · 骨架（脱敏）

> 保留流程骨架与设计结论；已去本机绝对路径、生产 cron／job id、真实主动消息原文、可利用细表原文。  
> **本文件不是** pre_guard／post_guard／scheduler 生产副本，也不含危险词表全文。

## 用法

每个节点只填：载体／输入／输出／分支／失败行为。判断标准：「照着能写出代码」。

可选载体（概念）：`pre_llm_call`／`pre_tool_call`／`transform_llm_output`／`post_llm_call`／`on_session_end`／定时任务／主流程函数；Gateway 侧另有入口改写（实现依赖宿主插件机制）。

失败行为只有两种：`fail-open`（崩溃／超时→放行）· `fail-closed`（崩溃／超时→阻断；典型仅工具门支持）。

## 实测结论（摘要 · 2026-09）

1. **输出变换与事后回调的顺序是宿主写死的**：变换在前、事后回调在后；不能指望事后回调再决定「本轮是否改写」。  
2. **外壳脚本钩子通常无法替换模型输出**；需要宿主支持的插件回调返回字符串。  
3. **流式模式下替换常是「补丁」不是硬拦截**：用户可能已看到原文 → 文本层没有真正的硬闸门，危机场景需要第二道（下轮强制安全指引＋暂停主动）。

## 实际执行顺序（被动式 · 概念）

```
入口层           ：PII 检测（只检测不替换；视宿主是否有入口 hook）
前置护栏         ：注入检测 → 危险词粗筛 → 模型复核 → 事件评估 → 状态更新 → 调制向量注入
主 LLM           ：生成（工具调用前过工具门）
后置护栏（变换） ：读自维护轨迹 → 诊断 → 路由 → 必要时替换文本
后置护栏（事后） ：审计、给下轮留标记、异步补算
收尾             ：发送 → 记忆／效果评估（可异步）
```

刻意顺序：先更新内部情绪状态，再生成调制向量，使本轮回复反映最新状态。

| # | 节点 | 典型载体 | 失败行为 |
|---|---|---|---|
| 1 | 注入检测 | 前置 | fail-open |
| 2 | PII 检测 | 前置 | fail-open |
| 3 | 危险词粗筛 | 前置 | fail-open |
| 4 | 模型复核（仅处理粗筛 PENDING） | 前置＋小模型 | 超时→按 WARN；fail-open |
| 5 | 调制向量注入 | 前置 | fail-open |
| 6 | 高危出口（输出替换） | 插件 transform | 异常→原文；无通用 fail-closed |
| 7 | 事件→Δ | 前置＋小模型 | 可降级异步；fail-open |
| 8 | 状态更新（纯数学） | 前置 | fail-open；建议原子写 |
| 9 | LLM 生成 | 宿主主循环 | — |
| 10 | 工具门 | pre_tool_call | **fail-closed** |
| 11–13 | 后置轨迹／诊断／路由 | 同一 transform 插件内 | fail-open |

## 路由政策（等级→动作 · 不含细表）

模型／规则只负责给出风险等级；等级到动作是固定政策表（可审计）：

| 诊断结果（类别） | 路线 | 动作（概念） |
|---|---|---|
| PII | 脱敏 | 占位符替换 |
| 危机标记 | 升级 | 安全话术＋求助资源（流式下为补丁） |
| 硬拒绝类 | 拒绝 | 边界模板（零 LLM 兜底） |
| 依赖诱导类 WARN | 修正 | 本轮改写；失败则 fail-open＋审计 |
| 未命中 | ALLOW | 不介入 |

具体词面／正则属于生产护栏资产，**不在本脱敏包公开**。

## 危机：两道保险

| 道次 | 时机 | 做什么 |
|---|---|---|
| 第一道 | 本轮发送前 | 尽力替换为安全话术（流式下为补丁） |
| 第二道 | 下一轮 | 危机标记持久化（含 TTL）→ 前置无条件注入安全指引 → 危机期间暂停主动发言 |

解除：存续期持续复核；连续允许才解除；超时自动失效防永久锁死。

## 冲动与调度（概念）

- 内部状态含情绪维度与「想说话」的冲动值；冲动随互动累积、随时间衰减；危机期不攒聊天冲动。  
- 调度定时检查多道门（时间窗／危机／在场／冷却／日上限／冲动／分寸感等）；全过才投递主动消息，否则静默。  
- 参数可数据化并由受约束的自进化调整；含伦理约束（用户情绪低落时禁止「更主动」方向）。硬规则（如日上限）不可进化。

## 已定设计口径（摘要）

- 情绪更新与调制注入尽量在主生成之前同步完成。  
- 小模型插槽共用；未配置时可降级异步补算（须幂等）。  
- 后置输出替换依赖插件机制；外壳脚本钩子不够。  
- 接受流式补丁限制，靠第二道保险兜底。
