# 情绪与性格设计（脱敏要点）

> 改写自设计讨论存档。已去私人原话粘贴、本机路径、可还原身份的细节。  
> 用途：记忆／情感模块的设计输入摘要。

## 0. 一页速览

| 问题 | 结论 |
|---|---|
| 情绪 vs 性格 | 用三个慢统计量（基线／波动／恢复速度）从已有交互数据估计，不强制问卷 |
| 怎么处理性格 | **不可干预，只能适应**（调系统期待，不试图改人） |
| 消解 | 指数衰减已有；分类型衰减为可选精化 |
| 处境记忆 | 处境标签＋冲击度 → 过滤／改写主动内容 |
| 联想伤害 | 半记忆 × 主动联想 = 伤害；正解倾向「情景包」记忆＋行为层规则 |
| 环境 | 环境影响基线漂移；**环境折扣永不作用于危机信号** |
| 模式退出 | 三层棘轮＋**用户授权退出**；允许回退 |

## 1. 情绪 vs 性格（state vs trait）

| 指标 | 算法（示意） | 含义 |
|---|---|---|
| 基线 | 愉悦维度的长窗滚动均值 | 长期偏低 ≠ 单次低落 |
| 波动 | 滚动标准差 | 大＝情绪化，小＝平稳 |
| 恢复速度 | 冲击后回到基线的半衰期 | 快＝韧性较好 |

判定要渐进：短观察只当「情绪」；连续数月稳定才升为「性格假设」。系统输出的是**置信度**，不是给人贴死标签。

原则：对情绪低落可以安慰陪伴；对性格悲观**不试图改人格**，并调整效果指标（不把「必须变开心」当成功）。

## 2. 处境记忆与信息强度

主动消息在发出前可过处境过滤（例如高负荷期减少「学习任务」类建议），或按处境改写措辞。重要事件带「冲击度」——决定避让区大小与系统应安静多久。

示例处境标签（合成示意，非真实用户档案）：

```json
{ "state": "high_load_period", "implications": ["fragmented_time", "avoid_heavy_study_tasks"] }
{ "state": "grief_recovery", "implications": ["high_sensitivity", "avoid_romance_topics"] }
```

## 3. 联想伤害与情景包

伤害常来自「选择性不完备」：系统记住了物件护理，却丢掉了情感来源。人类记忆偏情景整包；碎片化 fact 存储容易半记得。

设计倾向：

- 只记有情感分量的情景；人／物／场合／情绪同包、整包遗忘。  
- 行为层要点：**不主动制造失落提醒**；用户自己提起则正常接住；拿不准则沉默并降低主动频率。

更深的「隐藏关联」（整理房间偶遇信物）不可枚举——敏感期可减少行动类建议密度，并重视踩雷后的修复能力。

## 4. 模式系统（跨模块临时配置）

处境可触发模式；模式同时改内部冲动、表达密度、护栏策略与调度频率。退出建议三层棘轮，且**退出须用户授权**；允许因负向反应回退一层。

伦理锚点：只做帮助不做拯救；不替用户做选择；不诱导特定选择。

## 5. 环境层（摘要）

环境可影响情绪基线（节律、饭点等），但**不得**用环境理由折扣危机信号。归因歧义时先记候选原因，不猜单一原因。
